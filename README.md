# NLTA Tools — public test distribution

This repository contains a **public testing build** of NLTA Maya scripts from the private development workspace `MayaScriptBefore/ModuleGithub`.

- **Maya 2024 / Python 3**: run `AutoInstall.py` from Maya's Python Script Editor to install or update the Skinning, Setup, Scene, Research and Retarget Shelf buttons.
- Sources live in `UIs/` and `Libs/`; the Shelf downloads updates when a tool is opened.
- **No GitHub token, password or License Server is required** for this public test build.
- The private License Server, secrets, credentials, user JSON, project data, bytecode and vendor packages are not distributed here.
- This is a test release: Maya smoke testing is required before declaring production readiness.

**Public distribution means anyone can read and copy the code here.** Keep work-in-progress and future licensing infrastructure in the private repository.
